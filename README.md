# To-Do List Web App

A simple to-do list built with HTML, CSS, and vanilla JavaScript.

## Features

- Add new tasks
- Tick the checkbox to mark a task as done (text is crossed out)
- Delete a task to remove it permanently, even after a page refresh
- Tasks are saved in the browser (localStorage)

## Tech Stack

- HTML5
- CSS3
- JavaScript (DOM manipulation, localStorage)

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in any browser.

No build step or dependencies are required.
